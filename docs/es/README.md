# Documentación de Maat (Español)

`/docs/es` lo mantiene oficialmente en español el equipo core — no es
una traducción comunitaria. El resto de los idiomas viven en
`/docs/{locale}` y se agregan por pull request, con revisión de un
hablante nativo antes de mergear.

Contenido disponible una vez que el producto avance más allá de la Fase 0.
